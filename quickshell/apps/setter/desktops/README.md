# десктопы в сеттере

каждый `<wm>.json` регистрирует десктоп в списке вкладки `main`. имя файла — идентификатор WM (например, `driftwm`), `config` — путь к основному конфигу относительно корня дотов. если файл удалить, десктоп исчезнет из списка.

пока это только выбор конфига и подсказка о его расположении: сеттер ничего в нём не меняет. для чтения, записи и применения настроек понадобятся отдельные адаптеры каждого WM; общий `state.json` не описывает формат их конфигов.
